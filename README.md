# OrdKompis PT — aprenda sueco com explicações em português

Versão em português do **[OrdKompis](https://github.com/sagaryeole/OrdKompis)**, criado por **sagaryeole** ([site original](https://sagaryeole.github.io/OrdKompis/)).

O OrdKompis é um app web gratuito para praticar sueco: verbos, en/ett, adjetivos, preposições, ordem das palavras, pronomes, números, frases do dia a dia e quiz. O conteúdo de estudo continua **em sueco**; as explicações que no original estão em inglês estão sendo traduzidas para o **português do Brasil**, para quem aprende sueco sem falar inglês.

Palavras ainda não traduzidas aparecem em inglês.

## Como usar

Basta abrir o `index.html` no navegador. Não há instalação nem dependências: é HTML, CSS e JavaScript puro.

As traduções dos verbos ficam em `data/pt/verbs-pt.js`, no formato `"infinitiv": ["significado", "tradução da frase de exemplo"]`.
